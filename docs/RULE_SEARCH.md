# 自动规则搜索（受控筛选层）

更新时间：2026-08-08。本文描述框架新增的**有界、可审计的自动规则搜索**能力：
它让框架在预先登记的空间内自行尝试规则候选，但**只做筛选**，绝不自动发布，
晋升仍然必须走冻结 Campaign、最终锁箱与人工审批。

## 为什么需要这一层

原有框架是"一条冻结规则 → 一个研究 Case"：`run_frozen_campaign.py` 只执行协议里
固定的一条规则，`max_candidate_trials` 只是协议里登记的数字。要让框架"自己找规则"，
需要一层快速筛选：候选空间 → 向量化评估 → 跨候选多重检验 → 候选晋升。

## 搜索空间（第一版：23 个规则族、178 个候选）

DSL 已扩展窗口指标（`sma`/`ema`/`rsi`/`roc`/`max_high`/`min_low`/
`boll_upper`/`boll_lower`/`macd_dif`/`macd_dea`/`macd_hist`/`volume_ratio`）
与 `higher_close_count` 上下文；所有候选仍是 DSL 表达式，可被现有规则引擎编译执行。

## 与现有流水线的一致性

- 同一个 DSL 表达式由两套求值器执行：正式流水线用规则引擎（支持预计算指标列），
  搜索筛选用向量化求值器；二者用同一份 pandas 指标列，一致性由
  `tests/test_rule_search.py` 逐根比对保证。
- 成本、基准（000001 指数）、市场状态窗口、可成交性（涨跌停、ST 涨跌幅、量额缺失）、
  点时股票池过滤与 `T+1 开盘买入 → 固定 H 日收盘退出` 全部复用现有口径。
- 样本外分段与冻结 Campaign 一致（信号日 T，入场日 T+1，按入场日划分 OOS）。

## 运行方式

```powershell
python scripts/run_rule_search.py `
  --start 2010-01-01 --end 2023-12-31 --oos-start 2022-01-01 --lockbox-start 2026-09-01 `
  --symbol-limit 300 --output-root data/rule_search/round_20260808
```

产物（`data/rule_search/<round>/`）：

- `search_protocol.json`：预登记协议（空间、期间、股票池、成本、预算哈希），拒绝重跑；
- `round.json`：全部候选台账（定义、语义哈希、信号数、样本外统计、状态）；
- `candidates/<hash16>.json`：每个候选的完整统计摘要；
- `report.md` / `report.json`：通过筛选的候选排名。

## 第一轮结果（2026-08-08，开发股票池 300 只）

- 178 个候选，158 个通过"任一分组"筛选；其中 **146 个的最佳分组都是
  `20日/bearish`**（样本外均值约 +2%~+4%）。候选之间高度相关，说明该分组
  很可能是 2022–2023 熊市反弹的共性效应，而不是独立规则信号。
- **通过筛选 ≠ 规则有效**。FDR-BH 只校正"同一轮所有候选、全部分组"的统计量，
  不能消除候选之间因共用行情因子产生的相关性。
- 因此本轮结论是：搜索层可用，候选清单可作为研究起点，但**没有任何候选被晋升**。

## 第二轮（收紧口径）与审核结论

第二轮加入三道门槛后重跑同一搜索空间：

- **2×/3× 成本压力**：最佳分组必须在 2×、3× 成本下仍为正且 FDR 显著；
- **多周期一致**：通过分组至少覆盖 2 个不同持有周期；
- **相关性去重**：按信号 Jaccard ≥ 0.85 聚类，重复候选剔除。

结果：178 个候选中 78 个通过（第一轮为 158）。但审核发现一个强过拟合信号：
**所有通过分组的市场状态都是 bearish**（78 个全部含 `10日/bearish` 与
`20日/bearish`，零 bullish 通过）。结合开发股票池的弱幸存者偏差，这更像是
2022–2023 熊市反弹的共性效应，而非独立规则信号。

审核决定（记录于 `data/rule_search/round_20260808b/review.json`）：

- **晋升 1 条到冻结 Campaign 做全市场裁决**：`rsi_oversold@1.0.0`
  （RSI(14) < 30），理由：bearish 下 5 个周期全部通过、经受成本压力、
  机制经典、参数最少；晋升仅指进入冻结 Campaign，不构成发布；
- 备用候选：`breakout_60d@1.0.0`（60 日新高突破，趋势机制互补）；
- 2026-09-01 起的最终锁箱保持未读；发布仍需锁箱结果与正式双人工审批。

当前状态：`campaign_20260808T032005Z`（协议 `protocol_a666a614…`）已派生，
14/14 门禁通过，`rsi_oversold` 的全市场冻结执行已在后台运行。

### 冻结裁决（2026-08-08，`rsi_oversold`）

全市场冻结执行已完成（1,292,548 条样本外 Outcome），QA 为 `passed_with_limitations`：
派生 Campaign 后工作树代码变更导致 `code_snapshot_bound=false`，框架正确阻断审批路径。

统计裁决：**拒绝发布**。样本外净超额强依赖市场状态——仅 `bearish 5/10/20日`
为正（+0.28% / +0.62% / +2.38%），`bullish 10/20日` 显著为负（-0.38% / -1.55%），
`1日/bearish` 亦为负。这与筛选轮结论一致：`20日/bearish +2.38%` 是熊市反弹共性
效应，不是独立规则信号。假设草稿只选显著为正的分组、忽略显著为负分组，属结构性盲区。
完整裁决记录：`data/strategy_test_executions/protocol_a666a614…/adjudication.json`。

## 晋升路径（未自动执行）

1. 人工从候选清单挑选 1–3 条（建议先看非 `20日/bearish` 或跨周期一致的候选）；
2. 把规则定义加入 `packages/rules/catalog.py`（含语义哈希）；
3. 用 `scripts/derive_strategy_test_campaign.py` 派生新 Campaign，重跑 14/14 门禁；
4. `run_frozen_campaign.py` 在冻结协议内执行（不读取锁箱）；
5. 2026-09-01 起的最终锁箱 + Backtrader 独立复核；
6. 假设 → 规则双人工审批通过后才算发布。

## 已知限制与下一步改进

- 筛选口径偏宽：146/158 靠单一分组，后续可要求候选在 2×/3× 成本压力下仍为正，
  或要求跨多个周期一致，再或按信号相关性去重后排名。
- 开发股票池只取"验证期末仍活跃"的前 300 只，存在弱幸存者偏差；已登记在协议中，
  正式晋升前必须回到全量点时股票池。
- 搜索空间固定为一版（178 个）；新增规则族需先扩展 DSL 模板并重跑一致性测试。
- 所有搜索产物已加入 `.gitignore`，不入库；代码与文档变更仍需提交。
